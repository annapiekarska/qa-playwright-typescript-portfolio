# QA Playwright TypeScript Portfolio

A portfolio project demonstrating modern Quality Engineering practices using Playwright, TypeScript, API testing, schema validation, and GitHub Actions.

## Technologies

- Playwright
- TypeScript
- REST API Testing
- Zod Schema Validation
- GitHub Actions
- Page Object Model
- Fixtures
- Environment Variables

## Notes

This project uses JSONPlaceholder as a test API.

JSONPlaceholder simulates create, update, and delete operations and does not persist data changes. As a result, some API behaviors may differ from a production system.
